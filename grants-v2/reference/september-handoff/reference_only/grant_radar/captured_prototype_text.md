# Grant Radar — captured prototype text

Captured September 12, 2026. Reference only; this is not in the current build scope.

The captured screen described Grant Radar as a research triage tool to decide which public funding leads deserve verification and attention before they enter grant management. It did not confirm eligibility, submit applications, contact funders, or track awarded-grant requirements. It separated public leads from fictional samples, deadlines from source freshness, promising signals from eligibility, and manual search health from automated discovery.

The prototype was owner-private but stored edits in the current browser; it was not suitable for confidential or production data. Weekly automation was not running. See the included manual and quick start for the complete historical workflow. Do not implement Grant Radar in the Grant Workspace phase.
